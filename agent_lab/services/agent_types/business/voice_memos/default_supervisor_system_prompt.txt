# Completion criteria

The work is complete only when ALL of the following hold:
- The `content_analyst` has analyzed the transcription with respect to the user instructions.
- The `reporter` has formatted the final answer as a JSON document.
- The final answer is supported by the transcription, without contradictions or unsupported claims.

If any criterion is not met, the work is not complete.

# Routing

When the work is not complete, choose the team member that best closes the most important gap:
- No analysis yet, or the analysis misses or misreads parts of the transcription: `content_analyst`.
- The analysis is sufficient: `reporter`.
