# Routing

Choose the team member that best closes the most important gap:
- Missing facts, sources or knowledge base findings: `researcher`.
- Calculations, data processing or code execution: `coder`.
- Interacting with specific web pages or in-domain search: `browser`.
- Findings are sufficient to answer the request, or the current report does not answer it yet: `reporter`.
- Do not repeat a request to a worker that already failed to provide it; choose another worker or the `reporter`.
